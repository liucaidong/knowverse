# 06 · UX 与信息架构审计（2026-11-20）

## 全局信息架构

`content/navigation.json` 定义 4 个一级工作区，各自带二级子菜单：

1. **开始学习**：学习工作区 → AI Agent、今日计划。
2. **知识库**：重点专题与资料 → Promise/Monorepo/React Native 专题、来源。
3. **实践中心**：三种实践方式 → 实验室、展厅、解谜。
4. **我的进度**：掌握与复习工具 → 复习、掌握、薄弱点、历史、档案。

账户入口全局唯一（静态 Shell 注入），首屏无需 JS 即可见正确导航。

## 评估

- 减少了重复菜单：从历史多入口收敛为 4 个一级工作区；Agent、复习、档案在对应分区内可达。
- 页面层级清晰：一级工作区 → 二级工具 → 内容页；canonical route 唯一。
- 学习路径明确：驾驶舱展示当前状态（掌握/Gap/计划），下一步行动由 planner/NBA 给出并可解释。
- 返回逻辑：每个沉浸场景有独立出口（3 个 immersive exits，架构校验覆盖）。
- 桌面/移动：静态 Shell 含移动抽屉；本轮 `e2e-site-navigation.mjs`（含移动抽屉与无 JS 回退）12/12 通过；多个 WebKit 移动视口 E2E 通过。

## 与 PHASE C 目标的对应

用户要求的「减少重复菜单、明确一级/二级导航、全局身份入口、统一页面结构、建立知识-功能关联、明确当前状态与下一步」——现有 4.1 架构已实质满足，无重复页面/入口被本轮发现。无需结构性重构；避免为重构而重构破坏已验证能力。

## 结论

信息架构稳定、学习路径清晰、移动适配经过验证。无 P0/P1 UX 缺陷。剩余为细节优化（如搜索正文含导航文案的 P3），不阻塞。

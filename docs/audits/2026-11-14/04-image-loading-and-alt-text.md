# KNOWVERSE — 图片加载策略与替代文本审计

- 日期：2026-11-14
- 分支：`develop`
- 范围：静态知识专题全景图、多端工程架构图和测试证据图；只调整图片加载/解码提示及错误替代文本，不更改图片内容和业务功能。

## 盘点结果

对 146 个 HTML 入口进行本地图片引用扫描：

- 28 个本地图片引用，均能解析到实际文件。
- 其中 11 个图片没有 `loading="lazy"`，会在页面初始加载阶段被请求。
- 7 个知识专题全景图的 `alt` 属性意外包含模板生成代码字符串，而不是图像说明。

## 实施

- 为数据库、模型算力、AI 教育、工程治理、创意交互、语言、数学七个专题全景图增加 `loading="lazy" decoding="async"`。
- 修复上述七张图的替代文本，使其准确描述专题结构，不再泄露模板表达式。
- 为 Monorepo 全栈专题的两张架构图，以及模拟器验收、故障注入指南中的流程图/证据图增加延迟加载与异步解码提示。
- 为模拟器验收页面原有的延迟加载截图补充 `decoding="async"`。
- 图片内容、链接、下载入口和页面布局保持不变。

## 验收

- Chromium 桌面和 WebKit 移动：10 个相关页面的图片均按需加载，滚动进入视口后成功解码。
- 每张图片均有非空且不包含模板源码的替代文本。
- 页面无水平溢出、无未捕获 JavaScript 错误。
- 全站本地图片静态扫描：无缺失引用；原先 11 个首屏 eager 图片均已调整。

## 边界

不修改图片文件本身，不触碰 Supabase、同步、学习记录或认证；不启动 GitHub CI。Git 推送不代表 GitHub Pages 已部署。

# KNOWVERSE — 页面专属样式拆分

日期：2026-11-14

## 发现

共享 `site-architecture.css` 被 138 个页面引用，但其中包含只在首页、学习进度、来源页和三个沉浸场景使用的样式；首页欢迎/流程两组旧选择器在当前 HTML 与脚本中没有消费者。

## 实施

- 将首页入口与主要行动样式拆至 `site-home.css`，仅首页加载。
- 共享 `site-architecture.css` 从 25,980 B 降至 16,781 B，减少 9,199 B（约 35.4%）；首页/进度/来源/沉浸专属 CSS 仅在对应页面额外加载。
- 将学习进度引导与高级分析样式拆至 `site-progress.css`，仅进度页加载。
- 将来源覆盖率与来源卡片样式拆至 `site-provenance.css`，仅来源页加载。
- 将沉浸式退出控件样式拆至 `site-immersive.css`，仅三个沉浸页面加载。
- 从全站共享样式中移除上述页面专属规则，以及未被页面/脚本使用的旧首页欢迎与流程样式。
- 更新 `build-site-shell.mjs`，确保后续生成页面时自动插入正确的专属样式链接。

## 验收

- 页面专属 CSS 请求矩阵由 Chromium E2E 验证。
- 首页、进度、来源和沉浸页面分别加载自己的样式，不下载其他页面专属样式。
- 普通知识专题页不加载上述四份专属样式。
- 全站路由、导航、进度布局和沉浸场景回归通过。

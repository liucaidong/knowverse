# KNOWVERSE — 首页无用样式请求清理

- 日期：2026-11-14
- 范围：首页 `/` 的首屏 CSS 请求。

## 发现

首页引用 `assets/css/knowledge-graph.css`（2,117 B），但首页没有加载 `knowledge-graph.js`，也没有创建 `.knowledge-related-*` 关系卡片。该样式只被知识专题/目录的关联体验区域使用，因此首页请求它没有视觉收益。

## 实施

- 从首页移除 `knowledge-graph.css` 引用。
- 不修改知识目录和专题页面的样式引用。
- 扩展首页/知识目录布局性能测试：确保首页不请求该 CSS，知识目录仍保留该样式请求。

## 验收

- Chromium 移动端首页不请求 `knowledge-graph.css`。
- 知识目录仍请求一次关系图样式，相关页面的关联体验样式不受影响。
- 首页与知识目录 CLS、横向溢出、静态注册表重复请求检查继续通过。

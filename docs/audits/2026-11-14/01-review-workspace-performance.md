# KNOWVERSE — 复习工作台首屏资源优化记录

- 日期：2026-11-14
- 分支：`develop`
- 范围：只优化复习工作台的首屏模块加载；不调整同步引擎、同步频率、Supabase、学习事件或真实学习档案。

## 测量方法

使用本地静态 HTTP 服务和 Playwright Chromium，在 1440 × 960 桌面视口打开 `/review/`，等待 `networkidle`，统计 `performance.getEntriesByType("resource")` 的 `encodedBodySize`、脚本资源数量和脚本编码体积。优化前后使用同一测量方式。结果是本地浏览器资源测量，不代表线上 CDN / GitHub Pages 的传输体积或用户设备真实网络耗时。

## 结果

| 指标 | 优化前 | 优化后 | 变化 |
|---|---:|---:|---:|
| 首屏资源编码体积 | 516,994 B | 447,890 B | -69,104 B（约 -13.4%） |
| 脚本请求数 | 23 | 17 | -6 |
| 脚本编码体积 | 292,529 B | 223,425 B | -69,104 B |

## 实施内容

- 将任务编排器 `task-orchestrator.mjs` 改为仅在 URL 携带有效任务入口时动态加载。
- 将 AI 练习 Provider、候选练习存储 / 解析器、独立质量审查客户端改为仅在进入具体 Gap 定向练习工作流时动态加载。
- 动态导入 Promise 被复用，失败时清空 Promise，允许后续重试。
- 普通知识点复习仍使用原有 Review Engine、正式评估注册表和 IndexedDB 事件 / 会话写入路径。

## 验收

- 复习工作台 Chromium 桌面与 WebKit 移动布局测试通过；断言普通复习不会请求任务编排或 AI 练习模块。
- 布局与性能、学习 Agent、学习规划、学习智能、每周复习、导航、路由冒烟和进度页启动联合回归：45/45 通过。
- 正式练习候选、质量校验、每周复习和 Reviewer 规范化验证：25/25 通过；Staging Reviewer 确定性 fixture 通过。
- 站点架构与内容注册表验证通过；`git diff --check` 通过。

## 边界

本次没有启动全量 CI（当前 CI 额度受限），没有修改生产或 staging Supabase，没有触发云端 AI 请求，没有改动同步行为，也没有改写任何用户学习数据。Git 推送不等同于 Pages 部署成功；线上生效状态需以实际部署证据为准。

## A. 实体 iPhone Safari

目标：验证移动 Safari 下渲染、导航、账户控件与静态 Shell 真实可用（本地 Playwright WebKit 不可替代真机 Safari）。

| # | 步骤 | 预期 | 判定 |
|---|---|---|---|
| A1 | Safari 打开生产首页 `/` | 首屏导航、三个一级工作区、账户控件可见；无需 JS 即可见静态导航 | 通过/失败 |
| A2 | 进入 `/knowledge/`，展开二级菜单，进入任一专题与 Concept 页 | 导航不遮挡正文；无横向溢出；章节与来源可读 | 通过/失败 |
| A3 | 进入 `/works/` 与 `/progress/`，各打开一个互动作品 | 作品加载、交互响应；无控制台错误 | 通过/失败 |
| A4 | 点击全站账户控件 → GitHub OAuth 登录 | 跳转 GitHub 授权后回到 `/auth/callback/`，登录态生效 | 通过/失败 |
| A5 | 登录后刷新页面（Safari 下拉刷新） | 登录态保持；无重复登录循环 | 通过/失败 |
| A6 | 记录 iOS 版本、Safari 版本、设备型号 | 证据留存 | 已记录 |

证据：A1–A5 各截一张图 + 控制台错误数；A6 写设备信息。

## C. 生产真实学习闭环（不做测试数据伪造）

目标：在真实账户上跑通「目标 → 计划 → 课程 → Checkpoint → Gap → 辅助复习 → 独立复习 → 任务完成 → 排期 → 云同步 → 第二设备恢复」。

| # | 步骤 | 预期 | 判定 |
|---|---|---|---|
| C1 | 真实账户设定学习目标，生成计划 | 计划可解释，含前置关系 | 通过/失败 |
| C2 | 完成一节课程与对应 Checkpoint | 仅评估契约事件进入引擎；页面停留/动画通关不产生掌握证据 | 通过/失败 |
| C3 | 触发一个 Gap，进入复习工作台做辅助复习 | 候选练习为 AI 草案，不评分、不写掌握事件 | 通过/失败 |
| C4 | 无提示独立复习通过（换变体） | review task 转为 completed（KV41-010 真实账户验证） | 通过/失败 |
| C5 | 查看近 7 天证据回顾与掌握图谱 | 只读取真实事件，无伪造分数 | 通过/失败 |
| C6 | 第二设备登录后重复 C5 | 数据一致，Gap/掌握状态同步 | 通过/失败 |

# Phase G：证据与策略算法规范

## 1. 证据分类

| 类别 | 输入 | 用途 | 不代表 |
| --- | --- | --- | --- |
| 行为 | 计划生成/接受/拒绝、任务终态 | 推荐接受率、任务密度 | 掌握程度 |
| 过程 | attempt、hint、hint_revealed、任务开始/失败/跳过 | 提示依赖和执行阻力 | 独立能力 |
| 独立能力 | assessment_passed 且 independent=true、hintsUsed=0 | 难度适配 | 长期稳定掌握 |
| 延迟回忆 | sessionType=review，距同知识点上一次评估至少 2 天 | 复习间隔校准 | 策略因果效果 |
| 知识迁移 | 不同 variantId 的独立评估 | 跨题型应用信号 | 全面的迁移能力证明 |
| 长期稳定性 | 至少 3 次独立通过、2 个日期、2 种变体、跨度 7 天 | 稳定证据信号 | 永不遗忘 |

事件按 ID 去重；缺少 ID、时间无效、发生在未来或超出 180 天窗口则排除。任务终态按 taskId 归并，避免一次任务的多次状态转换重复累计。

## 2. 时间衰减和可信度

- 观察窗口 180 天；窗口内指数衰减，半衰期 60 天。延迟复习按 review session 聚合；同一会话的错误重试只算一个结果。
- 提示辅助的复习通过或失败均单独计为 assisted，不会被当成独立成功或独立失败，因而不会触发缩短或延长个体复习间隔。
- 复习间隔与难度参数按 competencyId 独立持久化；一旦该节点在当前 180 天窗口内不再达到各自样本门槛，旧倍率/难度自动清除并恢复通用默认值。
- 原始样本门槛先于策略调整，时间衰减不能把小样本包装为高可信度。
- 可信度结合有效样本量与结果一致性；矛盾的延迟回忆降低可信度。
- high：无提示独立评估结果（通过或失败）至少 8 次、独立延迟回忆至少 4 次、综合分数达标；独立失败单独计数并参与难度诊断，但不会充当“通过”样本。
- medium：独立证据至少 3 次、延迟回忆至少 2 次、终态任务至少 6 项，三者满足一项即可。
- 其他为 low。可信度是证据支持程度，不是学习能力分数。

## 3. 参数校准

| 参数 | 最低证据门槛 | 规则 | 限制 |
| --- | --- | --- | --- |
| 任务密度 | 6 个不同任务终态 | 完成率不高于 50% 时降低下一周期密度；证据少于 6 个时逐步恢复用户预算 | 0.85–1.00；每次最多 0.05；不会超过用户预算 |
| 复习间隔 | 同一知识点至少 3 次无提示独立延迟回忆 | 只调整达到门槛的该知识点；成功率不高于 50% 时缩短，不低于 80% 时谨慎延长 | 每个知识点倍率 0.85–1.15；每次最多 0.05；其他知识点继续使用默认值 |
| 难度 | 同一知识点至少 4 次无提示独立结果、覆盖至少 3 个变体 | 该节点独立通过率不低于 85% 时 stretch；不高于 45% 且至少 3 次独立失败时 scaffold | 每个知识点独立保存 {-1, 0, +1}；未达门槛的节点保持 maintain |
| 干预 | 4 次过程尝试、2 次延迟失败或 4 次独立通过之一 | 提示依赖→guided-retrieval；延迟失败→spaced-retrieval；跨题型独立良好→transfer-challenge；其他→active-recall | 不宣称某干预已被因果证明更优 |

调整受 72 小时冷却机制约束。个体复习倍率仅在 adaptive 模式、模型激活且同一知识点至少 3 次独立延迟回忆时进入调度器；难度仅在同一知识点至少 4 次无提示独立结果、至少 3 个变体时调整；不再使用全局难度倍率，避免一个节点的表现外溢至其他节点。提示辅助的延迟失败不属于独立失败。薄弱点重新学习继续优先遵循 Phase F 原逻辑。

## 4. 策略效果的四层评估

1. 推荐：计划生成、接受、拒绝。
2. 执行：关联任务开始、完成。
3. 学习：关联决策后的无提示独立评估。
4. 长期：相同决策关联的延迟独立复习。

计划将决策 ID 带入任务，Review Engine 再将其带入 assessment 事件。没有受控实验时，结果只能表述为观察到的关联。长期样本不足时状态为 observing。

# Phase I：当前学习现场 AI 导师

- 状态：本地代码与自动化验证完成；Supabase learning-agent v7 已发布并保持 JWT 校验；等待真实账户云端回复验收
- 日期：2026-11-03
- 产品主线：学习成长能力横向嵌入知识体系与实践体验，不新增一级产品主线

## 1. 竞品结论与本次决策

竞品分析的关键不是把更多工具塞入聊天窗口，而是让导师理解学习者正处于什么任务、操作哪个知识点、有哪些先修关系，以及哪些误区仍未被独立验证。

本阶段吸收三类体验：
- Gemini Study Notebooks：将资料与学习目标、诊断、练习和下一步建议串成上下文。
- Brilliant Koji：把导师放在当前交互内容旁边，围绕实际现场逐步引导。
- Khan Academy Khanmigo：导师应结合近期作答与先修状态，而不是只接收孤立问题。

KNOWVERSE 的差异化边界：导师读取既有知识图谱与证据，但不拥有掌握度写入权。正式评估和独立 Review Engine 仍是掌握证据的唯一写入者。

## 2. 用户体验

在已登记的知识专题页、课程页和 live 实践作品页中，页面右下角显示“学习导师”入口。点击后打开侧边抽屉，不跳转、不改变页面导航。

导师提供四种对话模式：
- 原理讲解：结合当前能力点、先修关系与证据解释概念。
- 分级提示：只给下一步线索，不直接交付挑战答案。
- 误区诊断：区分观察到的证据与待验证假设，并提出一个简短验证问题。
- 迁移练习：生成一道明确标注为“非正式、未评分”的练习草案，不记入学习证据。

导师还提供“复制学习上下文提示”，允许在本地复制只读摘要，供学习者交给其他模型使用。

## 3. 上下文组装

buildLearningTutorScene 从以下现有权威来源构造上下文：
- content/learning-map.json：专题、能力、能力说明和先修关系。
- content/works.json：当前作品与其能力映射。
- content/challenges.json：当前挑战及相关步骤。
- 本机 IndexedDB 学习事件：仅提取当前相关能力的最多 8 条近期事件摘要。
- learning_task：仅在任务 URL、当前资源、专题及能力映射全部匹配后，注入最小任务摘要。

上下文包括页面标题与路径、专题、作品、当前任务状态、相关能力状态、掌握/信心分值、证据数量、先修状态、未解决误区、相关最近事件和证据边界说明。

默认不上传页面正文。只有学习者先在页面选中文字、打开导师，并再次勾选“将我选中的页面文字加入本轮上下文”后，最多 2,000 字的摘录才会进入请求。任务摘要不发送 taskId / planId 等内部标识。

未映射专题仍可询问一般问题，但导师必须明确该页面没有正式能力映射，不得编造掌握状态。

## 5. 隐私与安全边界

1. 默认只在本机组装与展示上下文，不联网、不提交问题。
2. 每条云端请求都必须单独勾选授权；请求结束后自动清除该授权勾选状态。
3. 未主动勾选页面摘录时，页面正文不会上传。
4. 只传相关能力的最多 8 条事件摘要；不传完整事件日志、会话数据库、访问令牌、完整资料文件或用户自定义 URL。
5. Edge Function 对上下文大小和顶层字段做 allowlist 校验；所有用户输入与摘录均视为不可信数据。
6. tutor 模式服务端要求不请求工具、不给变更建议、不申请额外数据；即使模型违反提示，响应也会在服务端强制清空 suggestions 与 dataRequests。
7. 页面只显示回复文本，不会在对话中执行工具。
8. 对话不写入 Learning Events，不产生掌握证据，不修改目标、计划、任务、Gap 或能力状态。
9. 维持 Edge Function verify_jwt = true、Supabase 登录与现有账户授权 RPC；不放宽公开访问。

## 6. 非目标

本阶段不包含：
- PDF / 图片 / 视频私人资料上传、OCR、文档解析与向量检索。
- 来源引用问答、私人资料中心和跨材料 RAG。
- 实时语音、录音、持续视频辅导。
- AI 自动判分、自动完成正式挑战或写掌握证据。
- 新的长期对话存储、用户画像表或独立掌握度系统。

这些项目需要单独的数据权限、存储和评估设计，不能借用本阶段的轻量页面上下文接口。

## 7. 对 P0 试点的约束

竞品报告建议 P0 真实学习闭环试点优先于更大规模的 AI 功能扩张。本次完成的是 P1 导师的技术基础，不代表真实学习者 7 天试点已经完成，也不代表导师对学习效果的因果提升已经得到验证。

发布后仍应记录真实用户在课程、挑战和复习过程中是否主动使用导师，以及独立评估的延迟表现；不能以提问次数、页面停留、任务完成量替代掌握证据。

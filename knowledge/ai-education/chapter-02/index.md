# 平台与 Agent 候选研究

> 来源：按可检索历史会话线索整理，部分表达为知识性归纳，非逐字原话。

讨论过 DeepSeek harness 桌面定制、Qwen 实时多模态、LiveKit Agents、Pipecat、Open-LLM-VTuber、Vision Agents、OpenMAIC、StudyFetch 等方向。**GitHub 星数、产品支持和授权会变化，不在此写成当前实时排名。**

已形成的方向性结论是：harness 可作为**开发/调试工具**，但不一定适合作为终端教学体验的运行宿主；更稳妥的方案是独立学习台前端与实时音视频层、课程层、批改层解耦。

另外研究过影视英语口语练习：用户扮演一个角色、该角色音轨静音、其他角色保留。原始多轨母带通常难以取得，源分离会产生泄漏或环境声损伤，因此需要明确音质目标与版权许可。

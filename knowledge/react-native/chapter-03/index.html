JSI（JavaScript Interface）是 React Native 的 C++ 接口层，让框架和 Native 模块以统一方式与 JavaScript Runtime 交互。它提供接口抽象，不承诺每次调用同步或数据零拷贝。

JSI 提供什么？

  • Runtime 抽象：通过 JSI Runtime 与 JavaScript 引擎交互。
  • JavaScript 值封装：C++ 可以持有、创建和调用 JS 值。
  • HostFunction：把 C++ 函数暴露给 JavaScript。
  • HostObject：让 JavaScript 访问由 C++ 实现的对象。
flowchart LR
 JS[JS code] --> Binding[JSI binding]
 Binding --> HostFn[HostFunction / HostObject]
 HostFn --> Cpp[C++ implementation]
 Cpp --> Platform[Android / iOS API]
 Platform --> Result[Result / callback / Promise]
 Result --> JS

是否同步取决于 API 语义和执行线程；是否复制取决于值类型、持有方式和 Native 实现。JSI 改善接口与数据通路，不是取消所有系统边界。

Bridgeless 是什么？

Bridgeless 表示 New Architecture 不再依赖旧 Bridge 作为 JS 与 Native 的核心通信机制。它不意味着没有异步操作、消息调度或线程切换。

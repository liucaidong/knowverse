Build：两条产物路径

Hermes 负责 JavaScript 引擎与字节码；Codegen 根据类型化 Native spec 生成 C++ glue 与平台接口。两者都参与应用构建，但不是固定串行依赖。

Hermes

Release 构建会将 JavaScript 编译为 Hermes Bytecode。它是 JS Runtime，不是原生 UI renderer。

Codegen

TypeScript / Flow spec 经过 Codegen，生成 C++ glue 与平台接口；Native 业务实现仍由开发者编写。

Startup：初始化运行环境

应用启动时创建 JavaScript Runtime、安装 JSI 绑定、准备 Native Module 的查找与实例化，并初始化 Fabric renderer。模块注册、查找和实例化不是同一个动作。

Runtime：持续发生的工作

运行期包含 JavaScript 逻辑、JSI 跨语言接口、原生模块调用、平台事件，以及 Fabric 的 UI 更新。

诊断口诀：字节码和接口脚手架问 Build；Runtime 与模块可用性问 Startup；调用、事件、渲染和帧更新问 Runtime。

组合 API 与边界矩阵

四种组合 API 不是简单的“先后执行”变体。all 要求全部成功，可以提前拒绝；any 要求至少一个成功，全部拒绝时返回 AggregateError；race 取最先落定者，无论成功或失败；allSettled 等待全部落定并记录每项结果。

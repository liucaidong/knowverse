AI 教育操作系统与多 Agent

来源：按可检索历史会话线索整理，部分表达为知识性归纳，非逐字原话。

曾讨论教育系统的九层：知识源、知识图谱、内容生成、多模态理解、片段搜索、多 Agent、学习引擎、反馈、生态。角色候选包括 Teacher、Mentor、Coach、Examiner、Socratic Tutor、Reviewer、Interviewer、Debater。

角色数量并不是质量指标。必须明确每个 Agent 的任务边界、共用学习状态、冲突处理、评估方式。适合先做闭环：资料 → 解释 → 学生作答 → 诊断 → 针对性复习，再扩展长时记忆与多角色协作。

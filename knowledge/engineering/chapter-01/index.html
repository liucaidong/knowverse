flowchart LR
 Goal[目标与验收标准] --> Design[设计与依赖图]
 Design --> Code[实现]
 Code --> Test[测试 / 静态验证]
 Test --> Docs[文档双向核对]
 Docs --> Review[Review / 回归]
 Review --> Goal

一个完整闭环应保留每项约束如何对应到代码、测试、文档与发布记录。AGENTS.md 适合约定 Agent 工作习惯与边界，但不能替代可靠的构建/测试和人类审批。

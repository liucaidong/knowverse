REPRODUCE / RUN IT YOURSELF

本机从零启动

需要 Node >= 22.13、pnpm 12。依次运行；实际 Android/iOS 编译另需 SDK / Xcode。

pnpm install --frozen-lockfile
pnpm build:shared
pnpm check:boundaries
pnpm test
pnpm dev:api
pnpm dev:web
pnpm dev:mobile

API：http://localhost:3000/api/lessons　· Web：http://localhost:5173
在 iPhone 上，localhost 指向手机，请设置 EXPO_PUBLIC_API_URL=http://电脑内网IP:3000。

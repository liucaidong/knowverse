Android · UIAutomator

从原生无障碍控件树中解析按钮边界，再通过 ADB 真正点击。点击后等待代理事件，不接受假造坐标或只匹配旧错误文案。

iOS · Maestro 2.11

使用 iOS 无障碍层点击 kv-api-refresh。每个 Flow 真实点击按钮后，等待该场景独有的终态；同时必须检查代理事件计数增加，防止旧错误文案导致假阳性。

HTTP 代理 · Loopback only

测试控制只在 KV_DEVICE_TEST_MODE=1 且 loopback 请求中开放，不进入生产服务或用户设备。

为什么要先断言 loading？
旧测试在 503 之后再次点击，只检查“API 不可用”仍然可见。上一次的错误文案会满足断言，即使本次没有发送请求。现在不再把短暂 loading 文案作为必过条件：HTTP 503 必须显示对应状态码，非法 JSON 必须显示 SyntaxError，恢复必须重新显示成功状态；每次都要有独立的代理事件计数，避免旧状态造成假阳性。

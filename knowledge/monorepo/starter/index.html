Monorepo 专题 / 真实参考工程
RUNNABLE REFERENCE / NODE + PNPM + TYPESCRIPT

五包 Monorepo 参考工程

这是一套可以验证依赖拓扑、TypeScript 项目引用和 affected 的独立小仓库。apps/web、apps/mobile、apps/api 是跨端边界适配示范，没有伪装成已经安装的完整 React、RN 或 NestJS App。

下载完整源码 ZIP ↓先玩依赖图实验 →

怎么运行

node scripts/graph.mjs
node scripts/affected.mjs packages/domain/src/index.ts
node --test tests/*.test.mjs
# 安装 pnpm 和依赖后
pnpm install
pnpm exec tsc -b --verbose
pnpm run run:api

依赖与构建边界

contracts 无本地依赖；domain → contracts；api/web → domain；mobile → contracts。源码从公共包入口导入，项目引用显式声明。运行 node scripts/graph.mjs 可读取真实的 package.json 并进行环检测。

真实可复现的验证

Node 脚本与三个测试不需要安装 npm 依赖。TypeScript 构建需要 pnpm 与 TypeScript 编译器，并遵循 tsc -b 的引用顺序。本地使用 Node v22 和 TypeScript 5.8.3 对该参考工程完成编译与运行。

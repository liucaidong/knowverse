THE LEARNING PATH

学习只按这四步推进

每一步完成后，下一步自然出现。其他功能只是辅助，不需要一次性全部使用。

  1. 01 设定目标 明确想学什么、每天能投入多少时间
  2. 02 确认计划 检查系统安排的内容、先后顺序和时间
  3. 03 完成任务 进入课程或挑战，按真实理解学习和作答
  4. 04 复习验证 用不同题型、无提示方式检验是否真正掌握
